---
description: Mode belajar — jelaskan sebuah file/konsep di framework ini langkah demi langkah tanpa mengubah kode.
---

1. Tanyakan file atau konsep yang ingin dipelajari bila belum disebutkan (mis. `auth_interceptor.dart`, "ref.listen", "refresh token"; contoh fitur lengkap ada di branch `example`).
2. Baca file terkait dan `docs/architecture.md`.
3. Jelaskan dalam Bahasa Indonesia: tujuan file, posisinya di arsitektur (app/features/core), alur data, lalu baris-baris penting beserta alasannya.
4. Bila relevan, bandingkan dengan konsep GetX atau setState agar mudah dipahami.
5. Akhiri dengan satu latihan kecil yang bisa dikerjakan developer tanpa AI, plus cara mengecek hasilnya (`make test` / test mana).
6. Jangan mengubah file apa pun di workflow ini.
